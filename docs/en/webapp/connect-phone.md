# Connect phone

You work on your computer. Your phone should be in LuxStage too. **"Connect phone"** does that without typing your email address and password.

Your password stays your normal login. The code only saves the first sign-in on the phone.

## With a QR code

1. Open the show list and click **"Connect phone"** at the top right.
2. Open the **Camera** on your iPhone.
3. Point it at the QR code. Tap the notice.
4. The LuxStage app opens. You are signed in and see the show list of your team.

The dialog then shows **"Your phone is connected"**.

**Good to know**

- The code is valid for **5 minutes** and works **once**.
- While the dialog is open, the code renews itself.
- The code does not lead into a specific show. You pick the show on the phone afterwards.

### No app yet?

The code takes you to the App Store. Install the app, then scan the code on your computer **once more**. The code is lost while the app installs.

## By email to yourself

Click **"Email link to me"** in the dialog. The email goes to the address of your account.

Open the email on your phone and tap the link. The app signs you in.

- The link is valid for **7 days** and works **once**.
- Do not share the link.
- If the app is not installed yet, install it first. Then open the link again.

The email is only available if your server can send emails.

## Invalidate all links

Click **"Invalidate all links"** in the dialog. Open codes and email links then stop working. This helps if you sent a link you no longer want.

If your password changes, open links become invalid as well.

## If it does not work

| Message | What to do |
|---------|------------|
| "The code has expired or was already used." | Create a new code on your computer. |
| "You are already signed in." | Sign out in the app. Then scan the code again. |
| The dialog is missing | It is not in the demo. Sign in with your account. |

## Android

The Android app opens the same link. If the app does not open, open the link in the browser and tap **"Open app"**.
