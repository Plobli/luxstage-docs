# Editing in the apps

You can edit shows directly on site in the iOS and Android apps: long-press a channel, change it, save. The app must be online. Without a connection a notice appears and your input stays in the sheet.

::: tip Safety net
The **···** menu at the top right offers **Undo**, **Redo** and **History**. Shaking the device undoes the last change (with confirmation).
:::

## Long-press to edit

A tap does what it always did (for example checking something off). A **long press** opens a sheet with **Cancel** and **Save**. It works for:

| Where | What you edit |
|-------|---------------|
| Channel list | Channel: number, address, device, position, color, note, priority. Delete with confirmation |
| Setup | Notes and section titles |
| Photos | Caption, channel number, delete |
| Towers | Tower name, slot count, slot channel and note |
| Fly system | Element data and fixtures on the element |
| Shows list | Show details (name, date, season, venue, areas), archive |

## Dictation

Next to note fields there is a microphone button. **Hold** to speak, **release** when done. The text is appended to the existing note.

## Channel list

The **With note / All** switch shows only channels with a note, or all channels. Tapping the connection dot (OSC) opens the remote in full screen.

## Edit structure (pencil)

Adding, deleting and sorting change the structure. Tap the **pencil** in the **Channel list**, in the **Areas** tab, in towers and in the fly system. The show is locked for others until you tap **Done**.

- **Channel list:** add channels (**Add channel**), tap to change any field, swipe to delete (with confirmation), drag to reorder
- **Areas:** add, rename, delete and sort sections
- **Towers:** add and delete towers
- **Fly system:** add, delete and sort elements

## Create a show

**+** in the shows list starts a wizard: template, name and date, active areas, fly system, towers, summary.

## Not in the apps

Editing the drawing, bulk editing, duplicating or permanently deleting shows, import and template management stay in the web app.
