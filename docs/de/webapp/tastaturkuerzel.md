# Tastaturkürzel

Übersicht aller Tastaturkürzel der Web-App an einem Ort.

## Allgemein

| Aktion | Kürzel |
|--------|--------|
| Rückgängig | ⌘Z (Mac) / Ctrl+Z (Win) |
| Wiederholen | ⌘⇧Z (Mac) / Ctrl+Y (Win) |

## Grundriss-Editor

### Werkzeuge

| Werkzeug | Kürzel |
|----------|--------|
| Auswählen | V |
| Verschieben (Panning) | H |
| Linie zeichnen | L |
| Rechteck zeichnen | R |
| Ellipse/Kreis zeichnen | E |
| Text hinzufügen | T |
| Kreis platzieren | C |

### Aktionen

| Aktion | Kürzel |
|--------|--------|
| Rückgängig | Ctrl+Z |
| Wiederholen | Ctrl+Y / Ctrl+Shift+Z |
| Auswahl löschen | Delete / Backspace |
| Ansicht zurücksetzen | F / Ctrl+0 |
| Ansicht temporär verschieben | Leertaste gedrückt halten |
| Auswahl verschieben | Pfeiltasten (10 Einheiten mit Umschalt) |
| Kopieren / Einfügen | Ctrl+C / Ctrl+V |
| Duplizieren | Ctrl+D |
| Alles auswählen | Ctrl+A |
| Werkzeug abbrechen / Auswahl aufheben | Esc |
| Gitternetz ein-/ausblenden | G |

Details dazu in [Grundriss](./grundriss).

## Escape in Dialogen und Feldern

| Aktion | Taste |
|--------|-------|
| Foto-Lightbox schließen | Esc |
| Netzwerk-Vollbild beenden | Esc |
| Dialog „Neuer Bereich" abbrechen | Esc |
| Kreisliste-Suchfeld leeren | Esc |
| Zellenbearbeitung in Kreistabelle abbrechen | Esc |
| Farbauswahl-Dropdown schließen | Esc |
| Vorlage-Umbenennung abbrechen | Esc |
| Sidebar schließen (ggf. nach Umbenennung) | Esc |
