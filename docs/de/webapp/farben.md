# Farben verwalten

Die Vorlage **Farben** enthält alle Farbfilter deines Hauses: die mitgelieferten Lee- und Rosco-Filter und eigene Farben, zum Beispiel einen Frost-Filter aus deinem Lager. Die Farben gelten für alle Bühnen, alle Shows und alle PDFs.

## Öffnen

Unter **Vorlagen** steht der Eintrag **Farben** unterhalb der Bühnen-Vorlagen. Ein Klick öffnet die Liste.

## Liste durchsuchen

- **Suche:** Code, Code 2 oder Name eingeben.
- **Typ:** Farbe, Frost, Diffusion oder Neutraldichte.
- **Standard / Eigene:** zeigt nur mitgelieferte oder nur selbst angelegte Farben.

Jede Zeile zeigt Code (bei Standardfarben die Lee-Nummer, dahinter die Rosco-Nummer), Name, Typ und in wie vielen Kreisen die Farbe verwendet wird.

## Farbe bearbeiten

Ein Klick auf eine Zeile öffnet den Dialog. Du kannst alles ändern: Code, Code 2, Name, Typ, Anzeigefarbe und Notiz. Das gilt auch für Standardfarben. Änderungen wirken sofort in jeder Kreisliste.

Änderst du einen Code, ziehen alle Kreise mit der Farbe automatisch mit.

## Eigene Farbe anlegen

1. Klicke auf **„Neue Farbe"**.
2. Vergib einen Code, zum Beispiel `HF-1`. Der Code darf nicht wie eine Lee- oder Rosco-Nummer aussehen (kein `L201`, `R44` oder `201`).
3. Trage einen Namen ein und wähle den Typ.
4. Wähle die Anzeigefarbe und speichere.

Eigene Farben stehen in der Farbauswahl jeder Kreisliste ganz oben.

## Frost und Diffusion

Frost und Diffusion haben keine echte Farbe. LuxStage zeigt sie **schraffiert** mit Schrägstrichen, in der Kreisliste und im PDF. Je dichter die Striche, desto stärker die Streuung. Im Dialog wählst du **Leicht**, **Mittel** oder **Stark**. Die Grundfarbe darunter ist weiß, kann aber leicht getönt sein.

## Zurücksetzen und löschen

- **Auf Standard zurücksetzen** stellt eine geänderte Standardfarbe wieder her. Der Knopf erscheint nur, wenn die Farbe vom Standard abweicht.
- **Löschen** entfernt eine Farbe nach einer Warnung. Kreise, die sie verwenden, behalten ihren Code und alle anderen Angaben. Nur die Anzeigefarbe fehlt dann.
- **Standardfarben wiederherstellen** legt gelöschte Standardfarben neu an und ergänzt neue Filter aus der mitgelieferten Liste. Vorhandene und geänderte Farben bleiben unberührt.

## In den Apps

Die iOS- und die Android-App laden die Farbliste vom Server. Offline nutzen sie den zuletzt geladenen Stand.
