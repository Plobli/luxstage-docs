# Handy verbinden

Du arbeitest am Computer. Das Handy soll auch in LuxStage sein. Mit **„Handy verbinden"** geht das ohne Tippen von E-Mail-Adresse und Passwort.

Dein Passwort bleibt dein normaler Login. Der Code spart nur die erste Anmeldung am Handy.

## Mit QR-Code

1. Öffne die Show-Liste und klicke oben rechts auf **„Handy verbinden"**.
2. Öffne am iPhone die **Kamera**.
3. Halte sie auf den QR-Code. Tippe auf den Hinweis.
4. Die LuxStage-App öffnet sich. Du bist angemeldet und siehst die Show-Liste deines Teams.

Im Dialog erscheint danach **„Das Handy ist verbunden"**.

**Gut zu wissen**

- Der Code gilt **5 Minuten** und nur **einmal**.
- Solange der Dialog offen ist, erneuert sich der Code von selbst.
- Der Code führt nicht in eine bestimmte Show. Du wählst die Show danach am Handy.

### Noch keine App?

Der Code führt dich zum App Store. Lade die App, dann scanne den Code am Computer **noch einmal**. Der Code geht beim Laden der App verloren.

## Per E-Mail an dich selbst

Klicke im Dialog auf **„Link per E-Mail an mich"**. Die Mail geht an die E-Mail-Adresse deines Kontos.

Öffne die Mail am Handy und tippe auf den Link. Die App meldet dich an.

- Der Link gilt **7 Tage** und nur **einmal**.
- Gib den Link nicht weiter.
- Ist die App noch nicht da, lade sie zuerst. Öffne den Link danach noch einmal.

Die Mail gibt es nur, wenn dein Server E-Mails versenden kann.

## Alle Links ungültig machen

Klicke im Dialog auf **„Alle Links ungültig machen"**. Dann funktionieren offene Codes und Mail-Links nicht mehr. Das hilft, wenn du einen Link verschickt hast, den du nicht mehr willst.

Ändert sich dein Passwort, werden offene Links auch ungültig.

## Wenn es nicht klappt

| Meldung | Was tun |
|---------|---------|
| „Der Code ist abgelaufen oder schon benutzt." | Erzeuge am Computer einen neuen Code. |
| „Du bist schon angemeldet." | Melde dich in der App ab. Scanne den Code dann noch einmal. |
| Der Dialog fehlt | Er steht nicht in der Demo. Melde dich mit deinem Konto an. |

## Android

Die Android-App öffnet denselben Link. Öffnet sich die App nicht, öffne den Link im Browser und tippe auf **„App öffnen"**.
